## ① 接入层 —— 她怎么连上 QQ

| 小功能 | 通俗解释 |
| --- | --- |
| QQ 网关 | 一个中间程序，让她的 QQ 号能收发消息 |
| 白名单 | 只理名单里的群和人，陌生人一律忽略 |
| 黑名单 | 明确拉黑的人，连记忆都不记 |
| 断线重连 | 网络断了自动重连，不用你管 |

---

## ② 对话系统 —— 她什么时候说话、说什么

```
收到消息 → 判断要不要叫醒她 → 醒了 → 她决定回不回 → 发出去
```

| 小功能 | 通俗解释 |
| --- | --- |
| **唤醒规则** | 什么情况叫醒她（见下表） |
| **合并窗口** | 你连发 3 条，她等 7 秒一起看，不回三条 |
| **潜水模式** | 平时不掺和，被叫到才出现 |
| **主动开口** | 冷场 10 分钟，85% 概率自己找话 |
| **回看补漏** | 回完消息后，回头检查有没有漏回的 |
| **被叫必应** | @ 她、引用她 → 必须回一句 |
| **管理员例外** | 群里你说话，她必须接 |

**唤醒规则明细**：

| 触发条件 | 概率 |
| --- | --- |
| @ 她 / 引用她 | 100% |
| 叫她名字 | 100% |
| 提问 | 100% |
| 拍一拍 | 100% |
| 关键词（你家、小逾） | 100% |
| 熟人发言（4 人） | 100% |
| 其他人闲聊 | 20% |
| 冷场 10 分钟 | 85% |
| 她刚说完话的 10 分钟内 | 40% |

## ③ 人设系统 —— 她是什么样的人

| 小功能 | 通俗解释 |
| --- | --- |
| **人设卡** | 一份 6.7 KB 的说明书，写她是谁、怎么说话 |
| **锚点** | 5 条永不可改的核心（嘴硬、心软、有判断…） |
| **场合差异** | 群里闹、私聊软 |
| **硬规则** | 被叫必回、不解读表情包、不编不知道的事 |
| **自动复盘** | 每周一次，她自己提改进建议，你审批 |

---

## ④ 记忆系统 —— 她怎么记住事

```
三层存储（永不删）＋ 检索 + 归档重置
```

| 层 | 存什么 | 位置 |
| --- | --- | --- |
| **原始消息** | 每句话（带 id、谁说的） | `memory/sessions/` |
| **档案** | 对每个人的印象、好感 | `data/群友档案/` |
| **日记** | 她的主观记忆、心情 | `data/日记/` |

| 小功能 | 通俗解释 |
| --- | --- |
| **检索** | 她主动搜历史，3.5 毫秒出结果 |
| **隐私隔离** | 群里搜不到私聊内容 |
| **可溯源** | 每条摘要能翻回原话 |
| **归档重置** | 聊到 70% 满了，写归档再清空 |
| **备份** | 全套数据打包，带校验，能恢复 |

## ⑤ 语音系统 —— 她怎么说话

### 说话（TTS）

| 小功能 | 说明 |
| --- | --- |
| 文字转语音 | 用她的声音读出来 |
| 固定默认音色 | 试过 4 种语气，选了默认 |

### 唱歌（RVC）

| 小功能 | 说明 |
| --- | --- |
| 4 种模式 | 副歌/整首 × 伴奏/清唱 |
| 自动找高潮 | 跳过前奏，直接唱高潮 |
| 指定起点 | "从 1 分 20 秒开始" |
| 队列 | 一次只唱一首，排队 |
| 完成通知 | 唱完主动告诉你 |
| 超时提醒 | 10/30 分钟没好，她说"没唱成" |
| 手动终止 | 面板按钮或说"别唱了" |

| 小功能 | 说明 |
| --- | --- |
| 语音转文字 | 你发语音，她听得懂 |
| 独立运行 | 不受重启影响（计划任务 FeiyuASR） |

## 一图看懂（简化版）

```
你发消息
   ↓
①网关（管道）
   ↓
②唤醒判断（叫她吗？）── 不叫 → 睡觉
   ↓ 叫
③人设（她是谁）＋④记忆（她记得什么）→ 一起喂给模型
   ↓
她决定说什么
   ↓
⑤语音/⑥表达（怎么表现）
   ↓
发出去了
   ↓
④记忆（把这段存起来）＋⑦关系（好感变化）
   ↓
聊到 70% 满 → ④归档重置（写日记 → 清空）
```

## 三层"看不见"的东西

| 层 | 作用 | 出问题会怎样 |
| --- | --- | --- |
| **⑧运维** | 保证服务活着 | 她突然不说话 |
| **⑨面板** | 让你能管 | 你没法看她在干嘛 |
| **备份** | 防丢失 | 换机后她"失忆" |

---

## 一句话总结

**十个大类，四十多个小功能。核心就三件事：**

1. **她能被叫醒并回话**（①②③）
2. **她记得住并搜得到**（④⑦）
3. **她能用声音和画面表达**（⑤⑥）

**其余四个（⑧⑨⑩）是让前三件稳定运行、你能看见、她能成长。**
