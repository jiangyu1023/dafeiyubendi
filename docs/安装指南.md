# 前置软件安装指南

> 这份文档写给"完全不懂技术"的人，也写给 **DeepSeek Harness（DSH）** 直接照着做。
> 把整份文档丢给 DSH，它应该能一步步带你装完。

---

## 开始之前

本系统需要 4 样东西。**请按顺序装**，每装完一样确认一下再继续。

| # | 软件 | 必需 | 作用 |
| --- | --- | --- | --- |
| 1 | **Node.js 20+** | ✅ | 运行桥接程序 |
| 2 | **DeepSeek Harness** | ✅ | 模型与对话引擎 |
| 3 | **DeepSeek API Key** | ✅ | 调用模型（要花钱） |
| 4 | **SnowLuma** | ✅ | QQ 网关（**需你手动装，见第 4 步**） |
| 5 | Python + edge-tts | 可选 | 让她会说话 |
| 6 | ffmpeg + demucs | 可选 | 让她会唱歌 |

---

## 第 1 步：装 Node.js

### 要做什么

1. 打开 <https://nodejs.org/>
2. 下载 **LTS** 版本（左边那个绿色按钮）
3. 双击安装，一路"下一步"
4. 装完打开命令行，输入 `node -v`，看到 `v20.x.x` 或更高就成功

### 给 DSH 的说明

> 请检查用户机器上是否已安装 Node.js 20+（`node -v`）。如果没有，告诉用户去 https://nodejs.org/ 下载 LTS 版安装；安装必须由用户手动完成，不要用脚本代装。

---

## 第 2 步：装 DeepSeek Harness

### 要做什么

1. 打开 DSH 的官方发布页（由用户自行获取链接）
2. 下载对应系统版本（Windows 用 `.exe` 安装包）
3. 安装并启动
4. 首次启动会要求登录 DeepSeek 账号，按提示完成
5. 启动后**记住界面地址**（形如 `http://127.0.0.1:xxxxx`，端口每次可能不同）

### 给 DSH 的说明

> DeepSeek Harness 需要图形界面（Electron 应用），无法在纯命令行服务器上运行。请确认用户已装好并能启动它。

---

## 第 3 步：准备 DeepSeek API Key

### 要做什么

1. 打开 <https://platform.deepseek.com/>
2. 注册/登录
3. 进入"API Keys"，创建一把新的 Key（形如 `sk-xxxxxxxx`）
4. 复制保存好（只显示一次）
5. 充值少量金额（几块钱就能用很久）

### 给 DSH 的说明

> API Key 需要用户自己去平台创建，我们无法代生成。提醒用户：Key 不要发给任何人，也不要提交到 Git 仓库。

---

## 第 4 步：装 SnowLuma（**必须用户手动完成**）

> ⚠️ **这一步本程序不会代做。**
> SnowLuma 的许可协议（EULA §5.4）规定：把它并入第三方安装包、Docker 镜像，或**通过自动化脚本部署**，都必须先取得书面授权。
> 所以本程序**只检测、不安装、不启动**。

### 要做什么

1. 打开 <https://github.com/SnowLuma/SnowLuma/releases>
2. 选最新的 Release，下载对应平台的包：
   - Windows：`SnowLuma-vX.Y.Z-win-x64.zip`
   - Linux x64：`SnowLuma-vX.Y.Z-linux-x64.tar.gz`
   - Linux arm64：`SnowLuma-vX.Y.Z-linux-arm64.tar.gz`
   - 已有 Node 环境：可用更小的 `-lite` 版
3. **自己解压**到任意目录（例如 `<你的目录>\SnowLuma-221`）
4. 检查目录里有 `index.mjs` 和 `launcher.bat`
5. **自己双击** `launcher.bat`
6. 打开它提示的 WebUI 地址（默认 `http://127.0.0.1:5099`）
7. 用**手机 QQ 扫码登录**
8. 登录后确认 OneBot 端口已开（默认 3000）
9. 在该 WebUI 里找到 **access token**，复制下来

### 给 DSH 的说明

> **禁止**替用户下载、解压、启动 SnowLuma。
> 如果用户问怎么装，只给他 releases 链接和上面的步骤，让他自己完成。
> 装好后你可以检测 `http://127.0.0.1:3000` 是否连通来确认，但不要调用 `launcher.bat`。

## 第 5 步：配置本程序

### 要做什么

1. 进入程序目录（例如 `<你的目录>\qq-bridge`）
2. 复制配置模板：

```powershell
Copy-Item config.example.json config.json
```

3. 用记事本打开 `config.json`，改这几项：

| 字段 | 填什么 | 从哪来 |
| --- | --- | --- |
| `dsh.baseUrl` | `http://127.0.0.1:端口` | 第 2 步 DSH 界面地址 |
| `snowluma.accessToken` | 一串字符 | 第 4 步 SnowLuma WebUI |
| `ownerQQ` | 你的 QQ 号 | 你自己 |
| `allow.groups` | 群号数组，如 `["123456"]` | 你的群 |
| `allow.private` | QQ 号数组，如 `["123456"]` | 要允许私聊的人 |
| `socialV2.imageGen.apiKey` | 画图 API Key（可选） | 阿里云百炼等 |

4. 保存

### 给 DSH 的说明

> 帮用户改 config.json 时，逐项问清楚再填。`allow.groups` 和 `allow.private` 是白名单，不在名单里的群和人一律不理。

## 第 6 步：启动

```powershell
scripts\一键恢复.bat
```

**它会依次检查/启动：网关（只检测）→ 桥接 → 面板 → ASR。**

启动后打开 <http://127.0.0.1:3200> 看控制面板。

### 如果提示"网关未运行"

**这是正常的**——本程序不会替你启动 SnowLuma。请回到第 4 步，自己双击 `launcher.bat`。

## 第 7 步（可选）：让她会说话

需要 Python 3。

```powershell
# 1. 建虚拟环境
python -m venv voice\venv

# 2. 装 edge-tts
voice\venv\Scripts\pip install edge-tts
```

装完在面板「🔊 说话」里把「合成引擎」选 `edge`，把「允许发语音」打开。

### 给 DSH 的说明

> 如果用户装不好 Python venv，可以提示他装 Python 3 后执行上面两条命令；这只是装一个 2 MB 的包，不需要显卡。

---

## 第 8 步（可选）：让她会唱歌

唱歌需要分离人声（demucs）和换音色（RVC），体积大、对机器要求高。

| 方式 | 需要什么 | 说明 |
| --- | --- | --- |
| **原唱（original）** | ffmpeg + demucs + PyTorch | 不换音色，直接混原唱 |
| **换音色（rvc）** | 上面全部 + RVC 环境 + 音色模型 | 需要自己训练/找模型 |

**没有这些也能用其他功能，唱歌会返回"未安装"。**

## 排错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 面板打不开 | 面板没启动 | 跑 `一键恢复.bat` |
| 她一句话不说 | DSH 没连上 | 检查 `dsh.baseUrl` 端口 |
| 提示网关未运行 | SnowLuma 没启动 | **自己双击 launcher.bat** |
| 收不到群消息 | 白名单没加 | 在 `allow.groups` 加群号 |
| 改配置没生效 | 没热加载 | 重启桥接 |
| 说话没声音 | 没装 edge-tts | 看第 7 步 |
